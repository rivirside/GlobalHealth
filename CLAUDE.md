## Project Overview
A web app combining real-time disease outbreak alerts with health system capacity data for affected countries. No existing public tool does this — outbreak trackers show what's happening but not whether the local health system can handle it. 17 competitor tools analyzed; zero integrate both.

## Tech Stack
- **Frontend**: Next.js 15 + React + TypeScript + Tailwind CSS
- **Maps**: Leaflet + React-Leaflet
- **Charts**: Recharts
- **Data Pipeline**: Python scripts → JSON files in `data/`
- **Hosting**: Vercel (free tier)
- **Cost**: $0

## Commands
- `npm run dev` — Start Next.js dev server (http://localhost:3000)
- `npm run build` — Production build
- `npm run lint` — Run ESLint
- `python pipeline/fetch_outbreaks.py` — Refresh outbreak data
- `python pipeline/fetch_capacity.py` — Refresh capacity data
- `python pipeline/fetch_indices.py` — Refresh index data (GHSI, INFORM, SPAR)

## Conventions
- TypeScript strict mode throughout
- Components: PascalCase files and names
- Utilities: camelCase files and names
- All country references use ISO 3166-1 alpha-3 codes (e.g., "USA", "KEN", "IND")
- Data fetching happens in Python pipeline → JSON files, NOT at runtime in Next.js
- API routes are thin — they read from `data/*.json` and return filtered results
- Colors follow the design system in `docs/DESIGN.md`
- Disease categories: respiratory, vector-borne, diarrheal, hemorrhagic, vaccine-preventable, zoonotic, other

## Data Sources (all free, no API keys)
- WHO GHO API: `https://ghoapi.azureedge.net/api/`
- World Bank API: `https://api.worldbank.org/v2/`
- WHO DON RSS: `https://www.who.int/feeds/entity/don/en/rss.xml`
- GHSI, INFORM, IHR SPAR: Annual CSV downloads
