# Global Health Outbreak Context Dashboard

An interactive web application that combines real-time disease outbreak alerts with health system capacity data for affected countries. When an outbreak is reported, users can immediately see whether the affected country's health system has the resources to respond — hospital beds, physicians, immunization coverage, and more.

## The Problem

Outbreak trackers (WHO, HealthMap) tell you **what's happening**. Health system assessments (GHSI, HeRAMS, INFORM) measure **preparedness**. But no public tool combines both — forcing analysts to manually cross-reference multiple sources during every outbreak.

## Features

- **Interactive world map** with color-coded outbreak markers by disease category
- **Click any outbreak** to see outbreak details alongside the affected country's health system capacity
- **Capacity benchmarking** — indicators compared against WHO recommendations and regional averages
- **Country profiles** with full capacity data, historical outbreaks, and preparedness indices
- **Filters** by disease type, date range, and region
- **Auto-updating** outbreak feeds from WHO Disease Outbreak News

## Data Sources

| Data | Source | Update Frequency |
|------|--------|-----------------|
| Outbreak alerts | WHO DON API | Every 12 hours |
| Hospital beds, physicians, nurses | WHO Global Health Observatory API | Quarterly |
| Health expenditure, GDP | World Bank API | Quarterly |
| UHC Service Coverage Index | WHO GHO API | Quarterly |
| Immunization coverage (DTP3) | WHO GHO API | Quarterly |
| IHR Core Capacity scores | WHO SPAR | Annual |
| Global Health Security Index | NTI/JHU | 2021 edition |
| INFORM Risk Index | EU JRC | Annual |
| Fragile States Index | Fund for Peace | Annual |

## Tech Stack

- **Frontend**: Next.js 15, React, TypeScript
- **Maps**: Leaflet + React-Leaflet
- **Charts**: Recharts
- **Data Pipeline**: Python (requests, beautifulsoup4)
- **Hosting**: Vercel

## Getting Started

### Prerequisites
- Node.js 18+
- Python 3.10+

### Setup
```bash
# Install frontend dependencies
npm install

# Install Python pipeline dependencies
pip install -r pipeline/requirements.txt

# Fetch initial data
python pipeline/fetch_outbreaks.py
python pipeline/fetch_capacity.py
python pipeline/fetch_indices.py

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
